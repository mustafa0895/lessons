Exam Q24 · Free response (5–8 marks) · Lesson 3-1 · p. 135

Solve equations with variables on each side with rational coefficients

حل معادلات فيها متغيرات في الطرفين بمعاملات نسبية

Move the variable terms to one side (add or subtract the same term on both sides), then the numbers to the other side, then divide. With fractions, multiply both sides by the LCD first. Always check: put the answer back in both sides.

اجمع حدود المتغير في طرف واحد (بجمع أو طرح الحد نفسه من الطرفين)، ثم الأعداد في الطرف الآخر، ثم اقسم. إذا وُجدت كسور فاضرب الطرفين أولًا في المضاعف المشترك الأصغر للمقامات. تحقّق دائمًا بالتعويض في الطرفين.

Exam Q14 · Multiple choice (2–4 marks) · Lesson 3-2 · p. 143

Write linear equations in one variable and solve them

كتابة معادلات خطية بمتغير واحد وحلّها

Each person (or company) gives an expression: start + rate × x. "The same amount" means the two expressions are equal. Write start + rate·x = start + rate·x, then solve. If something goes down, use minus.

كل شخص (أو شركة) له مقدار: البداية + المعدل × x. وعبارة "المقدار نفسه" تعني أن المقدارين متساويان. اكتب البداية + المعدل·x = البداية + المعدل·x ثم حلّ. وإذا كان المقدار يتناقص فاستخدم الطرح.

Exam Q10 · Multiple choice (2–4 marks) · Lesson 3-3 · p. 149

Solve multi-step linear equations using the Distributive Property and like terms

حل معادلات خطية متعددة الخطوات باستخدام خاصية التوزيع وتجميع الحدود المتشابهة

Step 1: distribute (open the brackets; a minus before a bracket changes every sign inside). Step 2: combine like terms on each side. Step 3: solve as an equation with variables on each side.

الخطوة 1: وزّع (افتح الأقواس، والسالب قبل القوس يغيّر كل الإشارات داخله). الخطوة 2: اجمع الحدود المتشابهة في كل طرف. الخطوة 3: حلّ كمعادلة فيها متغير في الطرفين.

Exam Q11 · Multiple choice (2–4 marks) · Lesson 3-4 · p. 152–153

Write and solve multi-step linear equations with rational coefficients

كتابة معادلات خطية متعددة الخطوات بمعاملات نسبية وحلّها

Choose the unknown (for example the width w). Write the other quantity using w ("2½ more than twice" → 2w + 2½). Use a formula (perimeter P = 2ℓ + 2w) or "total = total". Then distribute, combine, solve, and check.

اختر المجهول (مثلًا العرض w). اكتب الكمية الأخرى بدلالة w ("أطول بـ 2½ من ضعفه" ← 2w + 2½). استخدم قانونًا (المحيط P = 2ℓ + 2w) أو "المجموع = المجموع". ثم وزّع واجمع وحلّ وتحقّق.

Exam Q12 · Multiple choice (2–4 marks) · Lesson 3-5 · p. 159, 167

Identify the number of solutions of a linear equation in one variable

تحديد عدد حلول معادلة خطية بمتغير واحد

Simplify both sides to the form ax + b = cx + d. Compare: different x-coefficients → one solution. Same x-coefficients and different numbers → no solution (you get something false like 4 = 0). Same coefficients and same numbers → infinitely many (you get something true like 2 = 2).

بسّط الطرفين إلى الصورة ax + b = cx + d ثم قارن: معاملا x مختلفان ← حل واحد. المعاملان متساويان والعددان مختلفان ← لا يوجد حل (تحصل على عبارة خاطئة مثل 4 = 0). المعاملان متساويان والعددان متساويان ← عدد لا نهائي من الحلول (تحصل على عبارة صحيحة مثل 2 = 2).

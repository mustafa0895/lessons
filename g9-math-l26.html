Lab · Commutative and associative

Swap the order, move the brackets

بدّل الترتيب، وحرّك الأقواس

Commutative: the order can change: a + b = b + a, ab = ba. Associative: the grouping can change: (a + b) + c = a + (b + c), (ab)c = a(bc).

الإبدال: يمكن تغيير الترتيب: a + b = b + a و ab = ba. التجميع: يمكن تغيير طريقة التجميع: (a + b) + c = a + (b + c) و (ab)c = a(bc).

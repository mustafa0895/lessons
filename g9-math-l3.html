Three properties of equality

ثلاث خصائص للمساواة

Reflexive: a = a. Symmetric: if a = b, then b = a. Transitive: if a = b and b = c, then a = c.

Identities, inverses and zero

المحايد والمعكوس والصفر

Pick a number for a. Watch what each property does.

اختر عددًا لـ a، وشاهد ماذا تفعل كل خاصية.

Additive identity: 0. Multiplicative identity: 1. Additive inverses add to 0, like 7 and −7. Multiplicative inverses (reciprocals) multiply to 1, like 2/3 and 3/2.

المحايد الجمعي: 0. المحايد الضربي: 1. المعكوسان الجمعيان مجموعهما 0 مثل 7 و−7. المعكوسان الضربيان (المقلوبان) حاصل ضربهما 1 مثل 2/3 و3/2.

Commutative and associative: mental math

الإبدال والتجميع: الحساب الذهني

Commutative: change the order, a + b = b + a, ab = ba. Associative: move the brackets, (a + b) + c = a + (b + c). Both work only when all operations are + or all are ×.

الإبدال: غيّر الترتيب. التجميع: حرّك الأقواس. وكلاهما يصلح فقط عندما تكون كل العمليات جمعًا أو كلها ضربًا.

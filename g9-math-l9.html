A skydiver lands about 360 seconds after jumping, give or take 30 seconds. So the landing time is 30 seconds from 360, early or late. Distances like this are absolute values!

Absolute value is a distance

القيمة المطلقة مسافة

The absolute value |x| is the distance of x from 0. A distance is never negative: |−5| = 5 and |5| = 5.

القيمة المطلقة |x| هي المسافة بين x و0. المسافة لا تكون سالبة أبدًا: |−5| = 5 و|5| = 5.

Solve with two cases

الحل بحالتين

If |a| = b and b ≥ 0, then a = b or a = −b. Case 1: inside = the number. Case 2: inside = its opposite. Write the solution set in braces { } and check each.

إذا كان |a| = b وb ≥ 0 فإن a = b أو a = −b. الحالة 1: ما بداخل القيمة = العدد. الحالة 2: = معكوسه. اكتب مجموعة الحل بين { } وتحقّق من كل حل.

Isolate the absolute value first

اعزل القيمة المطلقة أولًا

Undo + or − and × or ÷ that are outside the bars. When the bars are alone, split into the two cases.

اعكس الجمع أو الطرح والضرب أو القسمة الموجودة خارج الخطّين. عندما تصبح القيمة المطلقة وحدها، قسّم إلى حالتين.

When is the answer ∅?

متى تكون الإجابة ∅؟

Isolate the absolute value. If it equals a negative number, there is no solution: the empty set ∅. If it equals 0, there is one solution. If it equals a positive number, there are two.

اعزل القيمة المطلقة. إذا ساوت عددًا سالبًا فلا يوجد حل: المجموعة الخالية ∅. وإذا ساوت 0 فهناك حل واحد. وإذا ساوت عددًا موجبًا فهناك حلان.

Write an equation from two points

اكتب معادلة من نقطتين

Find the centre (the midpoint) and the distance from the centre to each point. Then write |x − centre| = distance.

أوجد المركز (نقطة المنتصف) والمسافة من المركز إلى كل نقطة، ثم اكتب |x − المركز| = المسافة.

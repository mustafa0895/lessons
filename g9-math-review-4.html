Exam Q13 · Multiple choice · Reveal p. 236 · Ex. 37–39

Graph and interpret linear functions

تمثيل الدوال الخطية بيانيًا وتفسيرها

Read b where the line crosses the y-axis. Find m = rise ÷ run between two points. Write y = mx + b.

اقرأ b من نقطة تقاطع المستقيم مع محور y. أوجد m = الارتفاع ÷ الإزاحة بين نقطتين. اكتب y = mx + b.

Watch out: A line going down from left to right has a negative slope.

انتبه: المستقيم النازل من اليسار إلى اليمين ميله سالب.

Exam Q18 · Multiple choice · Reveal p. 233, 236 · Ex. 6, 23–28

Graph and interpret linear functions

تمثيل الدوال الخطية بيانيًا وتفسيرها

Write the equation as y = mx + b. Plot b on the y-axis, then use the slope. y = 2 is a horizontal line.

اكتب المعادلة بالصورة y = mx + b. حدّد b على محور y ثم استخدم الميل. ‏y = 2 مستقيم أفقي.

Watch out: 4x + 9y = 27 is not ready: first y = −4/9 x + 3, so the line goes down.

انتبه: ‏4x + 9y = 27 ليست جاهزة: أولًا y = −4/9 x + 3، لذلك المستقيم نازل.

Exam Q11 · Multiple choice · Reveal p. 248 · Ex. 10–15

Apply dilations to linear functions

تطبيق التمدد على الدوال الخطية

g(x) = a·x: if |a| > 1 the line is stretched vertically (steeper). If 0 < |a| < 1 it is compressed vertically (less steep).

‏g(x) = a·x: إذا |a| > 1 يكون المستقيم متمددًا رأسيًا (أشد انحدارًا). إذا 0 < |a| < 1 يكون منكمشًا رأسيًا (أقل انحدارًا).

Watch out: Multiplying x is a dilation, not a translation. 1.5 > 1 → stretch; ¾ < 1 → compression.

انتبه: الضرب في x تمدد وليس انسحابًا. ‏1.5 > 1 ← تمدد، و¾ < 1 ← انكماش.

Exam Q14 · Multiple choice · Reveal p. 263 · Ex. 7–9

Identify and graph step functions

تحديد الدوال الدرجية وتمثيلها بيانيًا

⟦x⟧ is the greatest integer ≤ x. Each step has a closed dot on the left and an open dot on the right.

⟦x⟧ هو أكبر عدد صحيح ≤ x. لكل درجة نقطة مغلقة على اليسار ونقطة مفتوحة على اليمين.

Watch out: 3⟦x⟧ makes the steps jump by 3. A negative factor (−2⟦x⟧) makes the steps go down. ⟦−x⟧ swaps the dots.

انتبه: ‏3⟦x⟧ تجعل الدرجات تقفز 3. المعامل السالب (−2⟦x⟧) يجعل الدرجات نازلة. ‏⟦−x⟧ تبدّل النقاط.

Exam Q16 · Multiple choice · Reveal p. 265 · Ex. 18a–18d

Identify and graph step functions

تحديد الدوال الدرجية وتمثيلها بيانيًا

Work inside first, then take the greatest integer ≤ the result, then multiply: f(9.7) = 2⟦8.7⟧ = 2(8) = 16.

احسب ما بالداخل أولًا، ثم خذ أكبر عدد صحيح ≤ الناتج، ثم اضرب: ‏f(9.7) = 2⟦8.7⟧ = 2(8) = 16.

Watch out: For negatives go down: ⟦−2.25⟧ = −3, not −2.

انتبه: مع السالب انزل للأصغر: ‏⟦−2.25⟧ = −3، وليس −2.

Exam Q25 · Written (free response) · Reveal p. 263 · Ex. 1–6

Identify and graph piecewise-defined functions

تحديد الدوال المتعددة التعريف وتمثيلها بيانيًا

Graph each piece only on its own interval. ≤ or ≥ → closed dot; < or > → open dot. Then read the domain and range.

مثّل كل جزء فقط على مجاله. ‏≤ أو ≥ ← نقطة مغلقة، و< أو > ← نقطة مفتوحة. ثم اقرأ المجال والمدى.

Watch out: Find both end points by putting the break x-value into each piece.

انتبه: أوجد نقطتي النهاية بالتعويض بقيمة x الفاصلة في كل جزء.

Exam Q17 · Multiple choice · Reveal p. 257 · Ex. 28–31

Construct arithmetic sequences

إنشاء المتتابعات الحسابية

Arithmetic sequence: the same number d is added every time. d = term − previous term.

المتتابعة الحسابية: يُضاف العدد نفسه d في كل مرة. ‏d = الحد − الحد السابق.

Watch out: d can be negative: −9, −12, −15 … has d = −3.

انتبه: يمكن أن يكون d سالبًا: ‏−9، −12، −15 … فيها d = −3.

Exam Q26 · Written (free response) · Reveal p. 255 · Ex. 9–22

Construct arithmetic sequences · Apply the arithmetic sequence formula

إنشاء المتتابعات الحسابية · تطبيق صيغة المتتابعة الحسابية

d = a₂ − a₁. Next terms: keep adding d. nth term: aₙ = a₁ + (n − 1)d.

‏d = a₂ − a₁. الحدود التالية: استمر في إضافة d. الحد النوني: ‏aₙ = a₁ + (n − 1)d.

Watch out: Simplify aₙ, then substitute n = 7 to check the 7th term.

انتبه: بسّط aₙ، ثم عوّض n = 7 لإيجاد الحد السابع والتحقق.

Written question: solve it on paper and show every step, then open Show solution and compare.سؤال مقالي: حلّه على الورق واكتب كل الخطوات، ثم افتح طريقة الحل وقارن.

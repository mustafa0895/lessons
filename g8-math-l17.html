Learn · Number of solutions

One, none, or infinitely many

حل واحد، أو لا حل، أو عدد لا نهائي

The solution of an equation is a value of the variable that makes it true. An equation can have one solution, no solution (no value makes it true), or infinitely many solutions (every value makes it true).

حل المعادلة قيمة للمتغير تجعلها صحيحة. قد يكون للمعادلة حل واحد، أو لا يوجد لها حل (لا توجد قيمة تجعلها صحيحة)، أو عدد لا نهائي من الحلول (كل قيمة تجعلها صحيحة).
